# Акватель — демонстрационный прототип

Выполнены этапы 1–2 из `master.md`: фундамент, дизайн-система и оболочка магазина. Прототип не принимает реальные заказы.

## Запуск

Node.js 22.13+ и npm. Установить зависимости: `npm ci`. Запуск: `npm run dev`, адрес http://localhost:3000.

Проверки: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`. Production: `npm start` после сборки.

## Доступные страницы

- `/` — статус прототипа в общей оболочке; коммерческая главная появится на этапе 3.
- `/delivery`, `/about` — краткая информация о доставке и компании с источниками.
- `/catalog?category=…&q=…` — заглушка будущего каталога, принимает раздел и запрос из навигации.
- `/cart` — заглушка корзины с количеством из общего состояния.
- `/account` — информационная страница без авторизации и сбора данных.
- `/design-system` — палитра, типографика, интерактивные примеры компонентов.
- `/admin` — минимальная заглушка отдельного layout; полноценная админка на этапе 8.

## Архитектура

- `src/app/(store)` и `src/app/(admin)` — отдельные layout магазина и админки.
- `src/components/ui` — локальные shadcn/ui-компоненты и Radix-примитивы; конфигурация генератора — `components.json`.
- `src/components/shared`, `src/components/product` — общие и товарные компоненты.
- `src/domain/models.ts` — типы сущностей; деньги в рублях, сумма считается через целые копейки.
- `src/data/mock` — единые исходные данные и Zustand store с persist.
- `src/services` — асинхронный контракт репозитория и клиентский mock-адаптер.
- `src/features` — сценарии интерфейса; сейчас только витрина компонентов.
- `docs/source-audit.md` — источники, наблюдения, неподтверждённые условия.

`mockRepository` перед чтением восстанавливает единый Zustand store из localStorage (ключ `akvatel-demo-data-v1`). Для будущих клиентских экранов: дождаться `hydrateMockData()` в effect, показать Skeleton до окончания, затем читать тот же `useMockStore`. SSR начинает с seed, автоматическая гидратация отключена для предотвращения расхождения разметки. Не импортировать клиентский репозиторий в серверные компоненты. Для API реализовать `ShopRepository` другим адаптером.

Хранилище работает в пределах origin и браузера. Сброс — удалить ключ `akvatel-demo-data-v1` в DevTools → Application → Local Storage и обновить страницу либо вызвать `useMockStore.getState().reset()` внутри клиентского кода. Данные не синхронизируются между устройствами. Сохранять сюда можно только вымышленные демо-заказы; реальных персональных данных в seed нет. Витрина компонентов не изменяет товары, корзину или заказы.

## Дизайн-система

Inter, контейнер до 1280 px, desktop-сетка 12 колонок, шаг отступов 8 px, скругления 12–20 px, основные контролы 48 px. Семантические цвета и Tailwind-токены находятся в `src/app/globals.css`. Шрифт подключён через next/font и размещается локально в сборке; первая сборка требует доступ к Google Fonts. Поддержаны focus-visible, клавиатурный диалог и prefers-reduced-motion.

Зависимости Motion, React Hook Form, Zod и resolver подготовлены для следующих этапов. Полный интерфейс корзины, оформление и управление данными пока не реализованы. Для production потребуются API, защищённая админка, серверная валидация, БД, согласованные коммерческие данные и отдельная интеграция платежей.

## Оболочка магазина — этап 2

Двухуровневая sticky-шапка, меню категорий, поиск по опубликованным товарам, мобильное меню и подвал подключены только к layout магазина. Административная часть сохраняет отдельную оболочку. Диалоги поддерживают Escape, удержание фокуса и его возврат к исходной кнопке. Переход по ссылке закрывает меню.

`src/features/cart/store.ts` — отдельный Zustand store корзины (ключ `akvatel-demo-cart-v1`). `setQuantity(productId, quantity)` устанавливает количество, ноль удаляет позицию. Счётчик показывает сумму единиц, свыше 99 — «99+», доступное имя содержит точное значение. Состояние восстанавливается после монтирования, без расхождения SSR. Чтобы сбросить корзину, удалите этот ключ в DevTools и обновите страницу. Добавление товаров будет подключено в следующих этапах; витрина компонентов по-прежнему не меняет корзину.

Контакты и реквизиты сверены с a-tel.ru; график работы офиса не подтверждён и не показан. Спорные интервалы и неподтверждённая стоимость доставки не фиксируются. См. `docs/source-audit.md`.
